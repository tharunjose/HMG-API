# Loading animation after cancelling Google Maps

On the 2.5.0.2 trial, the owner saw the old turn disappear and a loading animation persist. The prior capture showed the stock cluster returns to its compass when Hyundai navigation ends. This pass compares the cluster service’s main display type, direction and trip fields while the animation is visible and after the native navigation route starts and ends. The USB saves 45 filtered samples and identifies the installed wireless hooks by their file hash. Allow about two minutes and use the completion notification.

1. Park and insert the USB. Approve the diagnostic and wait for “Idle capture started.”
2. If the loading animation is already visible, leave it on screen for 10 seconds. Otherwise start a Google Maps route, cancel it once its instruction appears and leave the animation visible for 10 seconds.
3. Start Hyundai navigation, wait for its cluster instruction and cancel the native route. Observe whether the compass returns.
4. At “Idle capture complete,” reconnect the USB to the Mac. If the diagnostic reports failure, return the USB then.

The diagnostic reads cluster fields. Its outputs are confined to the new CRETA-CLUSTER-IDLE folder and an existing folder will be preserved. It requires the exact SU2IFL.IND.0000.V010.001.260430 product. Stage 15 remains an experimental package. Starting and cancelling a Hyundai route is the previously observed workaround for stale cluster guidance.
